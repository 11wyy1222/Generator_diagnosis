# 半直驱阶次频谱与竞争门控 v2 三种子实验报告

## 1. 结论

当前 v2 **不通过模型替换准入，不合并到 `main`，继续保留 v1**。

- 开发验证集的6次训练均为366/366全对，但验证集中只有24条正常、342条异常，不能说明跨机组稳定性。
- `order spectrum-only v2` 三种子在两套冻结测试上高度不稳定，仅 seed2027 良好；seed2026和seed2028出现大规模漏报。
- `competitive gated v2` 在22#/38#上稳定，但13#的 seed2027 漏报149条，三种子稳定性和均值不如 v1 gated。
- 三个 gated 种子形成了差异很大的专家路由方式，门控并未学到稳定的“频谱/机理可靠性偏好”。
- 13#、22#/38#结果曾参与结构设计讨论，因此本报告属于冻结回归验证，不是全新盲测证据。

## 2. 固定数据与训练设置

- 训练对象：`SD_DEV_23`，912条。
- 验证对象：`SD_DEV_23`，366条，其中正常24条、异常342条。
- 13#测试：1818条，其中正常156条、异常1662条。
- 22#/38#测试：22#正常1155条、38#异常4040条。
- 随机种子：2026、2027、2028。
- 用户在首次 OOM 后将 v2 `batch_size` 从32调整为8；其他配置保持冻结。
- 因 batch size 与现有 v1 不同，v1/v2对比不是严格的单变量结构消融。
- 每个模型阈值仅由各自开发验证集冻结，测试时未重新选阈值。

## 6. 门控行为

门控权重定义为 `mechanism_weight`，频谱权重为 `1-mechanism_weight`。

- seed2026：13#正常样本机理权重均值0.9567、异常样本0.000032；22#正常0.9897、38#异常0.000042。
  该种子主要用机理专家识别正常、用频谱专家识别异常。
- seed2027：13#正常/异常机理权重均值分别为0.7448/0.1479；22#/38#分别为0.7905/0.0852。
- seed2028：13#正常/异常机理权重均值分别为0.1793/0.8330；22#/38#分别为0.1545/0.9362。
  该种子与seed2026基本形成相反路由，主要用频谱专家识别正常、用机理专家识别异常。

因此，竞争门控虽然能组合出较高指标，但不同种子的路由语义不稳定。当前门控更像利用两分支特征
再次完成分类，而不是学习可解释、可复现的“证据可靠度”。这不符合本次结构修改的核心目标。

## 7. 处置建议

1. 不部署 v2，不合并实验分支到 `main`，继续使用现有 v1 候选。
2. 不根据13#/22#/38#继续调参；这些数据已经被观察，继续修改会进一步污染测试含义。
3. 保留本次所有运行目录、冻结阈值、预测明细和门控日志用于审计。
4. 下一版若继续研究门控，应约束门控只使用独立的质量/可靠度特征，或加入专家独立训练与门控校准阶段，
   防止门控本身成为标签分类器；方案应先在开发验证内部确定，再等待新增盲测数据。
